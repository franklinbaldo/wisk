# Work session

Canonical execution role in the Wisk learning cycle. A Work session changes or investigates the external project and leaves a repository-resident raw trace that later independent Wiki sessions can study.

The canonical role is policy-neutral. Consumer work sessions specialize it with domain RunSpecs, context/access/output policies, and cadence.
